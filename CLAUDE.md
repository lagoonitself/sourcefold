# Sourcefold

Start every session by reading `HANDOFF.md`. It has what we're building, the current state, accounts and IDs, what's blocking, and the next steps in order. When the user says "continue", do the first unchecked item under "Next steps" in `HANDOFF.md`.

Also follow `AGENTS.md` (rules for all coding agents) and, for UI work, `docs/DESIGN.md`. The full spec is `docs/SPEC.md`; the done-and-remaining checklist is `docs/ROADMAP.md`.

When you finish a step, update `HANDOFF.md` (tick it, note anything learned) and `docs/ROADMAP.md`, then commit.
