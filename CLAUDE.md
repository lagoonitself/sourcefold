# Sourcefold

Start every session by reading `docs/dev/HANDOFF.md`. It has what we're building, the current state, what's blocking, and the next steps in order. Deployment accounts and IDs are in private memory, not the repo. When the user says "continue", do the first unchecked item under "Next steps" in `docs/dev/HANDOFF.md`.

Also follow `AGENTS.md` (rules for all coding agents) and, for UI work, `docs/dev/DESIGN.md`. The full spec is `docs/dev/SPEC.md`; the done-and-remaining checklist is `docs/dev/ROADMAP.md`.

When you finish a step, update `docs/dev/HANDOFF.md` (tick it, note anything learned) and `docs/dev/ROADMAP.md`, then commit.
